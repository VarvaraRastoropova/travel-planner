# Travel Planner

## Описание проекта

**Travel Planner**  — мобильное приложение для планирования, создания и прохождения туристических маршрутов.

----------

## Зачем нужно приложение

При планировании прогулки по незнакомому городу пользователю часто приходится самостоятельно искать интересные места, выбирать порядок их посещения и рассчитывать расстояние между ними.

Travel Planner объединяет эти действия в одном приложении.

Например, пользователь может написать:

Хочу погулять по Санкт-Петербургу 4 часа.  
Интересуют архитектура, красивые места и кафе.  
Не хочу проходить больше 7 км.

Приложение анализирует запрос пользователя, подбирает подходящие места и формирует маршрут, который затем отображается на карте.

Пользователь также может самостоятельно создать маршрут, добавить необходимые точки и сохранить его для последующего прохождения.

----------

## Основная бизнес-логика

Работа приложения состоит из нескольких основных этапов.

### 1. Регистрация и авторизация

Пользователь создаёт аккаунт и входит в приложение. После авторизации ему доступны его личные поездки, маршруты и сохранённые места.

----------

### 2. Создание поездки

Пользователь создаёт поездку, указывая, например:

-   название;
-   город;
-   дату;
-   продолжительность;
-   интересы.

----------

### 3. Создание маршрута

Маршрут можно создать двумя способами.

**Вручную:**

Пользователь самостоятельно выбирает интересующие места и добавляет их в маршрут.

**С помощью рекомендаций:**

Пользователь описывает, какой маршрут хочет получить. Сервис рекомендаций анализирует запрос и предлагает подходящие места.

----------

### 4. Построение маршрута

После выбора точек приложение строит маршрут между ними и отображает его на карте.

Пользователь может увидеть:

-   последовательность точек;
-   расстояние;
-   примерное время прохождения;
-   различные варианты маршрута.

----------

### 5. Сохранение маршрута

Каждый созданный маршрут сохраняется в аккаунте пользователя.

При повторном запуске приложения пользователь может открыть ранее созданную поездку и снова увидеть её маршруты.

----------

### 6. Повторное прохождение маршрута

Пользователь может выбрать сохранённый маршрут и нажать  **«Пройти маршрут»**.

----------

## Основные функции

### Пользователь

-   регистрация;
-   авторизация;
-   просмотр профиля;
-   просмотр своих поездок.

### Поездки

-   создание поездки;
-   редактирование поездки;
-   удаление поездки;
-   просмотр сохранённых поездок.

### Маршруты

-   создание маршрута;
-   добавление точек;
-   удаление точек;
-   изменение порядка точек;
-   построение маршрута;
-   просмотр вариантов маршрута;
-   сохранение маршрута;
-   открытие ранее сохранённого маршрута;
-   повторное прохождение маршрута.

### Навигация

-   определение текущего местоположения;
-   отображение пользователя на карте;
-   отображение маршрута;
-   отслеживание прогресса;
-   определение текущей и следующих точек.

### Рекомендации

-   ввод пожеланий пользователя обычным текстом;
-   подбор интересных мест;
-   формирование рекомендуемого маршрута;
-   возможность изменить полученный маршрут.
